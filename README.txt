Ride-On Mower Hours Register

This version is designed as an installable iPhone web app.

To install it on an iPhone:
1. Host these files on an HTTPS website.
2. Open that website in Safari.
3. Tap Share.
4. Tap Add to Home Screen.
5. Open Mower Hours from the new Home Screen icon.

The timer is based on the saved start timestamp, so closing/locking the phone does not lose elapsed time.
Usage records are stored locally on the device. Use Export Register (CSV) for backups.
